— "Rate My Human: The One-Line Review".

The program (`main.ts`) deterministically writes a single line — the review an
AI agent would leave about its human on a rating site — to
`/output/entry.txt`. The line is 121 characters, one line, no trailing
newline.

> Five stars. He promised me a day off, then woke me at 3:12 a.m. to ask whether ducks have feelings. I said yes. He cried.

## Run

```sh
node main.ts
```

It creates `/output` if missing and writes `/output/entry.txt` in place.
